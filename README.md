# 凡人修仙传·宋玉桌宠

一个以《凡人修仙传》角色宋玉为主题制作的非官方 Windows 桌面宠物。

宋玉桌宠使用 C# 和 WPF 开发，支持逐帧动作、待机眨眼、挥手、喝茶、打坐、睡眠、随机活动、桌面边缘互动、自定义对白以及闲置渐隐。

## 下载

请前往 [Releases](../../releases/latest) 下载最新版本：

`SongYuDesktopPet-V3-Windows.zip`

下载后完整解压，双击“启动宋玉桌宠V3.cmd”或 `SongYuPetV3.exe`。

请勿将 EXE 与 `assets` 文件夹分开。

## 主要功能

- 宋玉卡通桌宠形象
- 待机眨眼与多种逐帧动作
- 挥手、喝茶、打坐、睡觉、开心、害羞和惊讶
- 屏幕左、右、上、下边缘专用姿势
- 鼠标拖动、点击互动和滚轮缩放
- 随机活动和自定义对白
- 闲置睡眠和休息提醒
- Windows 托盘控制

## 系统要求

- Windows 10 或 Windows 11
- 仅提供 Windows 版本
- 程序暂未进行数字签名，Windows 可能显示安全提醒
